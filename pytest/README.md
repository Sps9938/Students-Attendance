# Pytest API Testing Setup

## Prerequisites
- Python 3.x
- Install dependencies:
  ```bash
  pip install pytest requests
  ```

## How to Run
1. Start your backend server (Node.js) so the API is available.
2. Run tests:
   ```bash
   pytest pytest/
   ```

## Example Test
See `pytest/test_health_check.py` for a sample health check API test.
